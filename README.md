# Nube Liquida
Nuestro proyecto se trata de un sistema de captacion de agua en el edificio M como prevencion a cortes de agua o falta de este recurso en general, la importancia del agua es indispensable para la realizacion de actividades academicas para tener un mejor ambiente educativo. Nuestro equipo se integra de Diego Avila, Noe Betancourt, Camila Ocegueda y Diego Del Angel
